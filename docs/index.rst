***********************
CHIMERApy Documentation
***********************

CHIMERApy is a Python implementation of the CHIMERA (Coronal Hole Identification
via Multi-thermal Emission Recognition Algorithm) coronal hole detection
algorithm.

This documentation is organised following the `Diátaxis <https://diataxis.fr>`__
framework, which separates material into four modes: :ref:`tutorials`,
:ref:`how-to-guides`, :ref:`reference` and :ref:`explanation`. The **example
gallery** is kept as a fifth top-level section, collecting runnable,
self-contained scripts.
